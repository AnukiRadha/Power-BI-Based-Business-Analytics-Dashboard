# Power BI Sales Dashboard

This project presents a sales analytics dashboard built in Power BI using the Superstore dataset. It focuses on tracking key business metrics, identifying sales trends, and providing an interactive view of performance across regions, categories, and time periods.

## Project Overview
The dashboard highlights important KPIs such as total sales, profit, quantity sold, and order count. It includes interactive filters and visualizations that help analyze business performance in a clear and presentation-friendly format.

## Key Features
- KPI cards for sales, profit, quantity, and orders
- Sales trend analysis over time
- Regional sales comparison
- Category-wise sales performance
- Interactive slicers for region and category
- Product-level insights in a detailed table
